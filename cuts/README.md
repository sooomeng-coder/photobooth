# 컷 프레임 (4컷 · 9컷 공용)

4컷/9컷을 찍을 때 고르는 **작은 프레임**. 4컷과 9컷이 같은 프레임 목록을 씀.

- **[여기에 이미지 올리기](https://github.com/sooomeng-coder/photobooth/upload/main/cuts)** — 파일 이름 아무거나, 여러 장 한꺼번에 OK
- 크기: **708×944** (세로 3:4, 반명함판 3×4cm). 비율이 달라도 초록/투명 구멍이 가운데 오도록 잘라서 맞춤
- 얼굴 자리는 순수 초록(#00FF00) 또는 투명
- 올리면 자동으로 `cut번호.png`로 이름이 바뀌고 고르기 화면에 `#번호`로 나옴 (올린 순서대로)
- 그리기 가이드: [templates/cut_3x4_guide@2x.png](../templates/cut_3x4_guide@2x.png)
- `cuts.json`, `thumbs/`, `cut*.png`는 자동으로 만들어지는 파일 — 직접 고치지 않아도 됨
