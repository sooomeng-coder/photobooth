# 1장 프레임 (아이패드 화면 크기)

"1장" 모드에서 고르는 **큰 프레임**.

- **[여기에 이미지 올리기](https://github.com/sooomeng-coder/photobooth/upload/main/frames)** — 파일 이름이 카드 이름이 됨 (예: `토마토.png` → 토마토)
- 크기: 아이패드 세로 **1640×2360** 권장 (가로 프레임은 2360×1640). 긴 변 2400px 넘으면 자동으로 줄임
- 얼굴 자리는 순수 초록(#00FF00) 또는 투명
- 반응형(LIVE) 프레임은 폴더째로 올림 (예: `눈물/` 안에 `background.jpg`, `eye-left.png` …) — 자세한 규칙은 저장소의 `CLAUDE.md`
