## 4컷 (인생네컷형 띠 2줄)

- 4×6 시트를 가운데(x=600)에서 자르면 2×6인치 띠 2개. 띠마다 **같은 4컷**
- 컷 비율은 9컷과 같은 **3:4** (276×368 @1x, 약 2.3×3.1cm). 그래서 **컷 프레임은 9컷과 같은 708×944 파일을 같이 씀**
- 컷 위치: `sheet_4x6_4cut.json` (`cells` 8개 = 띠 2개 × 4컷, `footers` 2개)
- 가이드: `sheet_4x6_4cut_guide.png` / `@2x.png`
