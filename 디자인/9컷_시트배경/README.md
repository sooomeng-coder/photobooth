# 9컷 시트 배경

9컷 결과 사진(4×6인치)의 **배경**. 사진 9칸은 이 위에 덮이니 칸 자리는 비워둬도 됨. 로고·날짜·무늬는 여기에.

- **[여기에 이미지 올리기](https://github.com/sooomeng-coder/photobooth/upload/main/디자인/9컷_시트배경)** — 파일 이름은 아무거나 (png / jpg)
- 크기: **2400×3600** (세로 2:3). 다른 크기면 비율 맞춰 가운데 기준으로 잘라서 맞춤
- **이미지는 한 장만** 두세요. 바꿀 땐 예전 이미지를 지우고 새로 올리기 (여러 장이면 이름순 마지막 것을 씀)
- 올리면 1~2분 뒤 자동으로 앱에 반영됨. 이미지를 지우면 기본 모양으로 돌아감
