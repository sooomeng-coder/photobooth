# 모드 선택 카드 — 4컷

시작 후 "4컷 / 9컷 / 1장" 고르는 화면의 **4컷 카드 그림**.

- **[여기에 이미지 올리기](https://github.com/sooomeng-coder/photobooth/upload/main/디자인/모드카드_4컷)** — 파일 이름은 아무거나 (png / jpg)
- 크기: 세로 **2:3** (예: 600×900)
- **이미지는 한 장만** 두세요. 바꿀 땐 예전 이미지를 지우고 새로 올리기 (여러 장이면 이름순 마지막 것을 씀)
- 올리면 1~2분 뒤 자동으로 앱에 반영됨. 이미지를 지우면 기본 모양으로 돌아감
