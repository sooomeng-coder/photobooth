# 시작 화면 배경

시작 화면(제목 · 안내 · 합성배경 1컷 / 자유 선택 9컷 · START) **뒤에 깔리는 배경 그림**.
글자와 카드는 앱이 그 위에 올리므로 배경 그림만 넣으면 됨. 기본은 하늘 그림을 흐리게 깔아 둔 상태이고,
여기에 올린 그림은 흐림 없이 그대로 깔림(흐리게 하려면 그림 자체를 흐리게 만들어서 올리기).

- **[여기에 올리기](https://github.com/sooomeng-coder/photobooth/upload/main/디자인/시작화면)** — 파일 이름 아무거나 (png / jpg)
- 크기: **1640×2360** (세로). 비율 다르면 가운데 기준으로 잘라 맞춤
- **한 장만** 두세요. 지우면 기본 배경으로 돌아감
- 제목·안내 문구는 `index.html`의 `CONFIG.START_TITLE`, `START_SUB` (말해주면 Claude가 바꿔줌)
