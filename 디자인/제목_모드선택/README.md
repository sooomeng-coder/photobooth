# 제목 — 모드 선택

"HOW MANY CUTS?" 자리에 들어갈 **제목 글자 이미지**. 투명 배경.

- **[여기에 올리기](https://github.com/sooomeng-coder/photobooth/upload/main/디자인/제목_모드선택)** — 파일 이름 아무거나 (png / jpg)
- 크기: 가로로 긴 이미지, 최대 **1200×240** 안에 맞춤
- **한 장(한 파일)만** 두세요. 바꿀 땐 예전 걸 지우고 새로 올리기 (여러 개면 이름순 마지막 것을 씀)
- 올리면 1~2분 뒤 자동 반영. 지우면 기본 모양으로 돌아감
